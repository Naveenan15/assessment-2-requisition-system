# Assessment 2 Requisition System

This Python program calculates purchase requisition totals. It automatically
approves requests below $500 and leaves requests of $500 or more pending
for manager review.

## Run the demo

Open the project folder in VS Code and run this command in the terminal:

```bash
python3 -B requestion.py
```

The demo processes five sample requisitions and shows the status counts
before and after manager review. A successful run ends with
`All demonstration checks passed.`
